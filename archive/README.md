# archive/ — что снято с производства и почему

Здесь лежит код, выведенный из сборки **Ф1-сужением** (2026-09-11). Он
**не компилируется, не импортируется и не тестируется** — ни один сборщик сюда
не заглядывает. Смысл каталога в том, чтобы удалённое оставалось видимым в
репозитории, а не только в истории git.

## Почему это снято

`contracts/src/` держал 28 верификаторов, 7 реестров и 13 хеш-бэкендов —
13 835 строк Solidity там, где продукту нужны единицы. Три причины убрать:

1. **Внешний аудит оплачивается по объёму.** 13 835 строк против 4 404 — разница
   порядка $250k против $80k.
2. **VFRI5–VFRI8 помечены «не деплоить в продакшен»** (нет last-layer
   FRI-проверки) и лежали в том же `src/`, откуда работают скрипты деплоя.
3. **Каждая лишняя версия — место, где документация расходится с кодом.**

Подробности и числа — в `ROADMAP.md` § 1.4 и `context.md`.

Каталоги `rust/` и `python/` — **не модули**: целыми файлами этот код никогда не
был, он жил внутри живых файлов. Каждый собран в один справочный файл с шапкой,
говорящей, откуда он извлечён.

## Как вернуть что-то в сборку

Целый файл:

```bash
git mv archive/contracts/src/QLSAVerifierV9.sol contracts/src/
cd contracts && QLSA_LOCAL_SOLCJS=1 npx hardhat compile
```

Фрагмент — скопировать определение обратно в исходный файл (шапка архивного
файла называет его) и прогнать соответствующий набор тестов.

## Что осталось в сборке

`QLSAVerifierVFRI11` (t=8), `QLSAVerifierVFRI12` (t=16), `QLSAVerifierRecursive`,
`BatchRegistryV5`, `BatchRegistryV7`, бэкенды Poseidon2 t=8 и t=16 и общие
библиотеки. Выбор между t=8 и t=16 **намеренно отложен** до Ф2 — см. `ROADMAP.md`.

## Предупреждение

Код здесь не поддерживается и не проверяется. Часть его содержит известные
пробелы в стойкости (VFRI5–VFRI8 — нет last-layer проверки; бэкенды t=2/t=4 —
коллизия узла ~2^31). **Не деплоить ничего отсюда.**
